Windows

Install

  1. Download OdinsGate-Setup.exe. The browser may say the file "isn't commonly downloaded": in Chrome open the downloads bubble and press Keep; in Edge press the three dots on the download, Keep, then Show more and Keep anyway.
  2. Run it. Windows shows "Windows protected your PC": press More info, then Run anyway. The installer isn't signed with a paid certificate, which is all that message means.
  3. The installer needs no administrator password: it installs for your user only, puts Odin's Gate in the Start menu (a desktop icon is optional) and offers to start it at the end.

A new PC with Smart App Control on blocks unsigned programs outright, with no "Run anyway". Tell Sam if that is what you see.

Play

Start Odin's Gate and press Play. The first start downloads the game client, about a minute; after that the game is up in seconds. Log in with a name and password you make up for this server, never the login of any other game or account; the first login with a name claims it.

Updates

The launcher updates itself when Sam publishes a new version. If it ever says "Please download the new installer", come back to the download page and run the new installer over the old one.

Where its files are, and uninstalling

The program lives under %LOCALAPPDATA%\Programs\OdinsGate; its settings and the game client under %LOCALAPPDATA%\OdinsGate. To remove it: Settings > Apps > Installed apps > Odin's Gate > Uninstall; that leaves the second folder, which you can delete by hand.

Problems

Press Copy problem report in the launcher and paste it to Sam. It holds the launcher's log and what it found out about the server, nothing from the rest of your PC.
