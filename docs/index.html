Odin's Gate

The launcher for Sam's private game server. Download it for your system, install it, and log in with a name and password you make up for this server. It fetches the game client the first time and keeps itself up to date.

Which Mac? Apple menu > About This Mac > Chip: "Apple M1", "M2" and so on is an Apple chip; "Intel Core" is Intel.

First start

The installers aren't signed with a paid certificate, so each system asks once whether you trust them. The guides walk through it:

  • Windows: the browser's "Keep", then "More info" and "Run anyway".
  • Mac: System Settings, Privacy & Security, "Open Anyway".
  • Linux: extract the archive and run OdinsGate/bin/OdinsGate.

Playing

  • Press Play. The first start downloads the game client, about a minute; after that the game is up in seconds.
  • Your name and password are for this server only. Never type the login of any other game or account here; the first login with a name claims it.
  • The launcher says in plain words when the server is offline, full or being updated, and offers Retry. When Sam updates the server while you play, it says "The server was updated" and a click restarts the game on the new version.
  • Something wrong? Press "Copy problem report" in the launcher and paste it to Sam.

Coming from RSProx?

Your settings don't carry over: the launcher keeps its own game settings, so set them again once. Your name and password are the same as before.

The game client is RuneLite, downloaded from runelite.net by the launcher itself; the launcher only ever connects to Sam's server.
