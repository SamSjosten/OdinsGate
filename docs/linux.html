Linux

Install

Download OdinsGate-linux-x64.tar.gz (x86-64 only) and extract it anywhere, for example in your home folder:

tar -xzf OdinsGate-linux-x64.tar.gz

That makes an OdinsGate folder with everything in it, its own Java included. Nothing is installed and no root is needed. Run

OdinsGate/bin/OdinsGate

or double-click that file in a file manager that runs programs. It needs a desktop (X11, or Wayland with XWayland) and the usual desktop libraries, which Ubuntu, Fedora and their relatives have.

Play

Press Play. The first start downloads the game client, about a minute; after that the game is up in seconds. Log in with a name and password you make up for this server, never the login of any other game or account; the first login with a name claims it.

Updates

The launcher updates itself when Sam publishes a new version. If it ever says "Please download the new installer", come back to the download page, extract the new archive over the old folder (or next to it) and run that one.

Where its files are, and uninstalling

Its settings and the game client are under $XDG_DATA_HOME/odinsgate, normally ~/.local/share/odinsgate. To remove it, delete the OdinsGate folder and that one.

Problems

Press Copy problem report in the launcher and paste it to Sam. It holds the launcher's log and what it found out about the server, nothing from the rest of your machine.
